# KrishiHat — ফ্রি AI চ্যাটবট সেটআপ গাইড (ধাপে ধাপে)

এই গাইড অনুসরণ করলে আপনার KrishiHat ওয়েবসাইটের ডানদিকের নিচের চ্যাট বাটনটি একটি **ফ্রি AI** এর সাথে যুক্ত হবে।
চ্যাট বক্সের ডিজাইন প্রজেক্টে আগে থেকেই ছিল, কিন্তু সেটা কোনো AI-র সাথে যুক্ত ছিল না। এখন যুক্ত করা হয়েছে।

---

## ১. চ্যাটবট কী কী করতে পারে

- বাংলা ও ইংরেজিতে প্রশ্নের উত্তর দেয় (ব্যবহারকারী যে ভাষায় লেখে)।
- **সব বিষয়ের প্রশ্নের উত্তর দিতে পারে** (সাধারণ জ্ঞান, পড়াশোনা, প্রযুক্তি, কৃষি ইত্যাদি)। এর জন্য API key বসানো থাকতে হবে। key ছাড়া শুধু ওয়েবসাইট সংক্রান্ত সীমিত উত্তর দেয়।
- ওয়েবসাইট ব্যবহারে সাহায্য করে: রেজিস্ট্রেশন, পণ্য যোগ করা, কার্ট, অর্ডার ট্র্যাকিং, দরদাম, পেমেন্ট, প্ল্যান।
- আপনার **ডাটাবেজ থেকে** মার্কেটে থাকা পণ্য (নাম, দাম, মজুত, জেলা, লিংক) খুঁজে উত্তর দেয়। যেমন: "আলুর দাম কত?"
- আপনার `market_benchmark_prices` টেবিল ও DAM রেফারেন্স ডেটা থেকে বাজার দর জানায়। ডেটা নমুনা বা অযাচাইকৃত হলে সেটা উত্তরে স্পষ্ট বলে দেয়।
- আগের ৪টি প্রশ্ন-উত্তর মনে রাখে (session এ), তাই ফলো-আপ প্রশ্ন করা যায়।
- **AI key না থাকলে বা AI সার্ভার সাড়া না দিলে** চ্যাট বক্স ভাঙে না; বিল্ট-ইন নিয়মভিত্তিক উত্তর দেয়।

**গোপনীয়তা:** AI-কে শুধু পাবলিক তথ্য (পণ্য ও বাজার দর) দেওয়া হয়। ব্যবহারকারীর ইমেইল, অর্ডার, পেমেন্ট বা চ্যাটের তথ্য AI-কে পাঠানো হয় না। শুধু ব্যবহারকারীর লেখা প্রশ্নটি AI প্রোভাইডারের কাছে যায়।

## ২. কোন ফ্রি AI ব্যবহার করবেন

| প্রোভাইডার | `.env` এ নাম | Key কোথায় পাবেন | মন্তব্য |
|---|---|---|---|
| Google Gemini (প্রস্তাবিত) | `gemini` | https://aistudio.google.com/apikey | বাংলা ভালো বোঝে, ফ্রি টিয়ার আছে |
| Groq | `groq` | https://console.groq.com/keys | খুব দ্রুত, ফ্রি টিয়ার আছে |
| OpenRouter | `openrouter` | https://openrouter.ai/keys | মডেলের নাম `:free` দিয়ে শেষ হতে হবে |

> **সতর্কতা:** ফ্রি টিয়ারের সীমা (প্রতি মিনিট/দিনে কতগুলো অনুরোধ), মডেলের নাম এবং ডেটা ব্যবহারের শর্ত প্রোভাইডাররা পরিবর্তন করেন। ব্যবহারের আগে তাদের ওয়েবসাইটে বর্তমান নিয়ম দেখে নিন। ফ্রি টিয়ারে প্রোভাইডার আপনার ব্যবহারকারীদের লেখা প্রশ্ন নিজেদের সেবা উন্নত করতে ব্যবহার করতে পারে কি না, সেটাও তাদের শর্তে দেখে নিন।

## ৩. ফাইল বসানো

zip এর ফাইলগুলো আপনার প্রজেক্ট ফোল্ডারে একই জায়গায় বসান।

**নতুন ফাইল (৫টি):**

```
app/Http/Controllers/ChatbotController.php   ← চ্যাটের API (রিকোয়েস্ট নেয়)
app/Services/AiChatService.php               ← AI প্রোভাইডারকে কল করে
app/Services/ChatbotKnowledge.php            ← ডাটাবেজ থেকে তথ্য খোঁজে + ব্যাকআপ উত্তর
tests/Feature/ChatbotTest.php                ← অটোমেটিক টেস্ট
docs/AI_CHATBOT_SETUP_BN.md                  ← এই গাইড
```

**পরিবর্তিত ফাইল (৫টি):**

```
routes/web.php                               ← POST /chatbot/message রুট যোগ হয়েছে
config/services.php                          ← 'chatbot' সেটিংস যোগ হয়েছে
.env.example                                 ← নতুন ENV ভেরিয়েবল যোগ হয়েছে
resources/views/layouts/app.blade.php        ← চ্যাট প্যানেলে endpoint যোগ + স্বাগত বার্তা
resources/js/app.js                          ← চ্যাট ফর্ম এখন সার্ভারে বার্তা পাঠায়
```

> আপনি যদি এর মধ্যে এই ৫টি পরিবর্তিত ফাইলে নিজে কিছু বদলে থাকেন, তাহলে ফাইল ওভাররাইট না করে উপরের বর্ণনা অনুযায়ী শুধু ওই অংশগুলো হাতে যোগ করুন।

## ৪. ধাপে ধাপে সেটআপ

### ধাপ ১: ফ্রি API key নিন (Gemini উদাহরণ)
1. https://aistudio.google.com/apikey এ যান এবং Google অ্যাকাউন্ট দিয়ে লগইন করুন।
2. **Create API key** চাপুন এবং key টি কপি করুন।

### ধাপ ২: `.env` ফাইলে key বসান
প্রজেক্টের `.env` ফাইল খুলুন (না থাকলে `.env.example` কপি করে `.env` নাম দিন)। নিচের লাইনগুলো যোগ করুন বা মান বদলান:

```env
CHATBOT_PROVIDER=gemini
GEMINI_API_KEY=এখানে_আপনার_key_বসান
GEMINI_MODEL=gemini-2.5-flash
```

Groq ব্যবহার করতে চাইলে:

```env
CHATBOT_PROVIDER=groq
GROQ_API_KEY=এখানে_আপনার_key_বসান
GROQ_MODEL=llama-3.3-70b-versatile
```

### ধাপ ৩: কনফিগ ক্যাশ পরিষ্কার করুন
প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে চালান:

```bash
php artisan config:clear
php artisan route:clear
```

### ধাপ ৪: ফ্রন্টএন্ড বিল্ড করুন (জরুরি)
`resources/js/app.js` বদলেছে, তাই এটি আবার বিল্ড করতে হবে।

```bash
npm install          # প্রথমবার হলে
npm run build        # প্রোডাকশন/সাধারণ ব্যবহারের জন্য
# অথবা ডেভেলপমেন্টে: npm run dev
```

### ধাপ ৪.৫: key ঠিক আছে কি না পরীক্ষা করুন (গুরুত্বপূর্ণ)

```bash
php artisan chatbot:test
```

- `AI কাজ করছে` লিখলে সব ঠিক আছে।
- অন্য কিছু লিখলে সেখানেই কারণ বলা থাকবে (key ভুল, মডেলের নাম ভুল, ফ্রি সীমা শেষ ইত্যাদি)।
- `.env` ফাইল বদলালে সার্ভার বন্ধ করে (Ctrl+C) আবার `php artisan serve` চালান।

> ডেভেলপমেন্টে (`APP_DEBUG=true`) চ্যাট বক্সে ব্যাকআপ উত্তরের নিচে "ডেভেলপার নোট" দেখাবে কেন আসল AI কাজ করেনি।

### ধাপ ৫: সার্ভার চালান ও পরীক্ষা করুন

```bash
php artisan serve
```

ব্রাউজারে http://127.0.0.1:8000 খুলুন → ডানদিকের নিচের সবুজ চ্যাট বাটন চাপুন → লিখুন:

- `আলুর দাম কত?`
- `আমি কীভাবে পণ্য বিক্রি করব?`
- `অর্ডার ট্র্যাক করব কীভাবে?`

### ধাপ ৬: টেস্ট চালান (ঐচ্ছিক)

```bash
php artisan test --filter=ChatbotTest
```

## ৭. সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| চ্যাট সবসময় সাধারণ ব্যাকআপ উত্তর দেয় | `.env` এ key ঠিক আছে কি না দেখুন; `php artisan config:clear` চালান; `storage/logs/laravel.log` এ "chatbot: AI provider failed" লাইনটি দেখুন |
| লগে 404 বা "model not found" | প্রোভাইডার মডেলের নাম বদলেছে। প্রোভাইডারের ডকুমেন্টেশন দেখে `.env` এ `GEMINI_MODEL` (বা অন্যটি) ঠিক করুন |
| লগে 429 | ফ্রি সীমা শেষ। কিছুক্ষণ পরে চেষ্টা করুন বা অন্য প্রোভাইডার ব্যবহার করুন |
| চ্যাট বাটন চাপলে আগের পুরনো বার্তা ("AI সার্ভিস সংযুক্ত নয়") দেখায় | `npm run build` (বা `npm run dev`) চালানো হয়নি; চালিয়ে ব্রাউজারে Ctrl+F5 চাপুন |
| 419 (Page Expired) | পেজ রিফ্রেশ করুন; `.env` এ `APP_URL` ও `SESSION_DOMAIN` ঠিক আছে কি না দেখুন |
| `composer install` এ PHP সংস্করণের সমস্যা | আপনার `composer.lock` ফাইলের কিছু প্যাকেজ **PHP 8.4.1 বা তার বেশি** চায় (composer.json এ লেখা ^8.2)। PHP 8.4 ব্যবহার করুন, অথবা `composer update` চালিয়ে lock ফাইল আপডেট করুন |

## ৮. নিরাপত্তার নিয়ম

- API key **শুধু** `.env` ফাইলে রাখুন। কোডে বা GitHub-এ কখনো দেবেন না (`.env` আগে থেকেই `.gitignore` এ থাকার কথা, দেখে নিন)।
- key ফাঁস হয়ে গেলে প্রোভাইডারের ড্যাশবোর্ড থেকে সেটি বাতিল করে নতুন key নিন।
- চ্যাটবট ব্যবহারকারীর কাছে পেমেন্ট, পাসওয়ার্ড বা অন্য ব্যবহারকারীর তথ্য দেয় না। সিস্টেম প্রম্পটে এই নিয়ম আছে এবং কোডেও এসব তথ্য AI-কে পাঠানো হয় না।
- বাজার দরের উত্তর **আপনার ডাটাবেজের ডেটার** উপর নির্ভর করে। এখনকার DAM ডেটা ডেমো/অযাচাইকৃত, তাই চ্যাটবটও তা নমুনা তথ্য বলে জানায়। আসল দর দেখাতে চাইলে অ্যাডমিন প্যানেলের "Market Imports" থেকে যাচাইকৃত ডেটা আমদানি করুন।

## ৯. পরবর্তী ধাপ (ঐচ্ছিক)

- **Python AI সার্ভিস:** আপনার প্রস্তাবনায় থাকা Python (FastAPI) দিয়ে দামের পূর্বাভাস মডেল বানিয়ে `AiChatService` এ আরেকটি সোর্স হিসেবে যুক্ত করা যায়।
- **চ্যাট ইতিহাস ডাটাবেজে সংরক্ষণ:** বিশ্লেষণ ও উন্নতির জন্য প্রশ্ন-উত্তর আলাদা টেবিলে রাখা যায় (ব্যবহারকারীর সম্মতি নিয়ে)।
- **ভয়েস ইনপুট:** গ্রামের কৃষকদের জন্য ব্রাউজারের Speech Recognition দিয়ে কথা বলে প্রশ্ন করার সুবিধা।
